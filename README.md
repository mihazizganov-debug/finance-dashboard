# 🏦 Финансовый Дашборд (Finance Dashboard)

**Курсовой проект** | Python-разработка | Skypro  
Дашборд для анализа банковских транзакций с тремя основными функциями:

## 📱 1. Главная страница дашборда (main_page)

Веб-интерфейс с JSON-ответом, содержащим:

✅ **Приветствие по времени суток**  
✅ **Статистика по банковским картам**  
✅ **Интеграция с API курсов валют** (актуальные курсы USD/EUR)  
✅ **Интеграция с API биржевых данных** (котировки акций)  
✅ **Автоматические отчёты в JSON формате**  
✅ **Расчёт кешбэка** (1% от потраченных средств)  
✅ **Топ-5 транзакций** (самые крупные операции)  

**Формат вывода:** структурированный JSON для веб-интерфейса

## 💰 2. Инвесткопилка (investment_bank)

Сервис для автоматического накопления средств:

✅ **Округление сумм до лимита** (10/50/100 ₽)  
✅ **Фильтрация по месяцам** - только транзакции указанного месяца  
✅ **Расчёт инвестиций** - сумма округлённых остатков  
✅ **JSON-отчёт** - структурированный результат  

**Пример:** транзакция 1712 ₽ при лимите 50 ₽ → инвестиция 38 ₽

## 📅 3. Траты по дням недели (spending_by_weekday)

Аналитический отчёт о расходных привычках:

✅ **Анализ за 3 месяца** - скользящий период  
✅ **Средние траты по дням** - Пн-Вс с нулевыми значениями  
✅ **Обработка ошибок** - корректные сообщения об ошибках  
✅ **JSON-формат** - детализированный отчёт  

**Пример вывода:** "Понедельник: 1950.0 ₽", "Вторник: 1500.0 ₽"

## ✨ Особенности моего проекта

### 🎯 Три независимых модуля:
1. **Главная страница** - готовый веб-интерфейс с API
2. **Инвесткопилка** - автоматическое накопление с округлением
3. **Анализ привычек** - траты по дням недели за 3 месяца

### 🛡️ Качество кода:
- **95% покрытие тестами** - выше требований курса
- **Типизация (mypy)** - статическая проверка типов
- **Black + Isort** - автоматическое форматирование и сортировка импортов
- **Flake8** - соответствие PEP8

### ⚙️ Гибкая настройка:
- `user_settings.json` - выбор валют и акций
- `.env` - безопасное хранение API ключей
- Конфигурация под разные сценарии

## 🚀 Быстрый старт

```bash
# Клонирование репозитория
git clone https://github.com/[твой-username]/finance-dashboard.git
cd finance-dashboard

# Создание виртуального окружения
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate  # Mac/Linux

# Установка зависимостей
pip install -r requirements.txt

# Настройка API ключей
cp .env.example .env
# отредактируйте .env, добавив свои API ключи

# Запуск приложения
python main.py
